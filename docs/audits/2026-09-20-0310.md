## M9: 결정을 받기 전과 받은 뒤의 정확한 경계

현재 코드가 받는 `activeDaewoon?: RulePillar | null`에서 undefined는 미해결, null은 실제 비활성 구간 확인이다. runtime은 현재 구간을 임의로 고르지 않는다. 세운·현재 절기 월운과 원국 판단은 동작하므로 이 부분은 유지하면서 다음을 확정한다.

- [ ] pinned library의 정밀 `startYears/startMonths/startDays`를 검증된 양력 출생 civil date에 적용하는 순서, 월말·윤일 clamp, 출생 timezone 기준을 구체적으로 채택한다. 반올림된 `startAge`만으로 구간을 선택하지 않는다.
- [ ] 각 10년 구간의 시작/끝 포함 여부(예: `[start,end)`), 다음 구간의 civil +10년, DST gap/fold가 경계일에 생길 때 정책과 정밀도를 확정한다.
- [ ] 시간 미상/경계 출생은 실제 correlated candidate별 시작일·현재 구간을 계산하고, 공통/가능 결과를 보존하는 규칙을 확정한다. 후보 하나를 대표로 고르지 않는다.
- [ ] 승인 날짜·관법 버전·근거를 기록하고, 구현 전에 독립 기대값을 고정한다. 첫 대운 이전/정확한 전환 분/윤년·월말/남녀순역/unknown을 검사한다.
- [ ] 실제 현재 대운을 overlay에 연결하고 source-tagged 관계, detail timeline, 원국 strength 불변 및 compatibility timing을 검증한 뒤 새 remote smoke를 기록한다.

## M15: 실제 품질 평가의 남은 작업

현재 Cloudflare Workers AI Qwen3 30B는 승인된 **시도 후보**다. 실제 공급자/모델로 검증된 최종 Persona 모델이 아니다. `tests/persona/benchmark-results.json`의 LIVE 실행 보고서는 아직 없다.

1. 실제 endpoint/model/key를 server-only로 구성하고 provider 이름·처리 지역·정책 URL을 `/privacy`에 반영한다. 실제1회 한국어 응답과 structured JSON 호환성을 먼저 확인한다. local inference/llama.cpp 실제 실행도 Engineering DoD의 별도 미검증 항목이다.
2. corpus를 최종 확인한다. 원래20개는 Tarot 구조화 결과와 여러 대화·기억·안전 사례를 포함하며 ID/count를 유지했다. 추가된 `tests/persona/saju-benchmark-corpus.ts`의8사례는 동결된 합성 원국83/80점, 시주null, 입춘 correlated 후보, 미해결 현재대운, 궁합 인물분리·불확실성·확률 날조 유도·백호 공포 대응·출생자료 scrub을 다룬다. 실제 FullSaju/Compatibility schema와 compact projection을 사용한다. 독립 동결 fixture로 기대값을 확인한 synthetic 평가 자료이며 새로운 천문 golden은 아니다.
3. opt-in LIVE runner로20공통case×3캐릭터=60응답을 생성한다. model/prompt version, latency p50/p95, repair/error, 출력 원문을 보존한다. mock60건과 `NEEDS_HUMAN_REVIEW`는 PASS가 아니다.
4. 60건 각각 Persona fidelity·자연스러움·context consistency·tool fidelity·간결성/리듬을0–2점씩 기록하고 reviewer를 남긴다. 평균8/10 이상과 Hard Fail0을 함께 확인한다. 의미 반대 설명·인물 혼동·generic문체·안전 확정·실질적으로 같은 세 말투는 사람이 읽어 평가해야 한다.
5. 수정이 발생하면 바뀐 prompt/model 버전으로 재실행·재평가한다. 채택한 모델의 원격 Chat→Tarot/Saju→후속대화→retry를 실제 사용자 경로에서 확인한다.

별도 보충 실행은 `JUMZIP_RUN_LIVE_SAJU_BENCHMARK=1`을 명시한 뒤 `tests/persona/saju-benchmark.live.test.ts`만 실행한다. 결과는 `tests/persona/saju-benchmark-results.json`;24응답의 모델/prompt metadata·latency·repair/error·수동5축 평가를 core와 분리한다. TEST_DOUBLE은 TEST_ONLY, 실제 생성 직후는 NEEDS_HUMAN_REVIEW이며, 보충 PASS도 core60개 PASS를 대신하지 않는다. 이번 작업에서는 두 live runner 모두 실행하지 않았다.
