# 응답 서비스 오류 진단 · 2026-09-20

17:11 KST에 운영 Qwen 모델로 합성 문장 한 건을 보냈습니다. API는 HTTP 429, 코드 4006과 일일 무료 사용량 제한을 가리키는 문구를 반환했습니다. 자동 재시도는 하지 않았고 사용자 대화·DB·계정 작업도 없었습니다. [안전한 진단 기록](evidence/workers-ai-availability-20260920-1711.json)에 상태와 허용된 신호만 남겼습니다.

Cloudflare 대시보드는 같은 시점에 오늘 5.68k/10k를 표시했습니다. 이 숫자와 API의 거부 사유가 다른 원인은 확인되지 않았습니다. [공식 정책](https://developers.cloudflare.com/workers-ai/platform/pricing/)의 초기화는 UTC 00:00, 한국 시각 09:00이며 다음 예정 시각은 9월 21일 09:00입니다. 해당 시각의 복구를 검증한 것은 아닙니다. 실제 응답의 코드 4006을 공식 오류 표의 3036과 같은 코드라고 단정하지 않습니다.

운영 v4는 요청 제한·인증·설정·서버 연결 실패를 모두 외부 `LLM_UNAVAILABLE`로 반환합니다. 이전 화면은 이 오류에 보미의 고정 문구인 ‘연결이 잠깐 끊겼어’를 붙였습니다. 실제 네트워크 장애를 확인한 설명이 아니었습니다.

## 수정과 배포

- 운영 응답의 `details.reason=LLM_RATE_LIMITED`를 읽어 요청 제한으로 표시합니다. 단순 429만으로 할당량·초기화 시각을 추측하지 않습니다.
- 인증·설정·원인 미상 서비스 실패에는 서비스를 이용할 수 없다고 안내합니다. 네트워크 전용 안내는 `NETWORK_ERROR`에만 사용합니다.
- 요청 제한 안내의 ‘잠시 후’와 중복 서버 문구를 제거했습니다. 타로의 저장된 카드와 같은 카드 재시도 동작은 유지합니다.
- 기존 채팅 대기 표시·즉시 사용자 메시지·모바일 타로·한국어 줄바꿈 개선도 이번 프런트엔드에 포함했습니다.

관련 UI 테스트 102개, 지정 파일 lint, 전체 typecheck, production build, 공개 빌드·소스의 credential 검사가 통과했습니다. 검증된 174개 파일을 Cloudflare Pages에 업로드했고 성공 화면을 확인했습니다. 17:18 KST [공개 빌드 비교](evidence/frontend-service-errors-public.json)에서 HTML·JS·CSS 10개가 로컬과 모두 일치했습니다. 새 브라우저 업로드 세션에서 폴더 업로드가 성공했으며 사용자의 수동 업로드는 더 이상 필요하지 않습니다.

## 남은 제한

이번 배포는 프런트엔드만 변경합니다. API의 무료 사용 제한은 해제되지 않았으며 유효한 신규 AI 응답이나 전체 공개 사용자 흐름을 검증하지 못했습니다. 운영 백엔드는 Qwen / Persona-v4 / Intent-v1을 유지합니다. v12 후보와 별도 v4.1 수정본은 배포하지 않았습니다.
