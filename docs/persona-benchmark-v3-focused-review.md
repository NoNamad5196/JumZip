# Persona v3 focused 실제 평가

2026-09-20, 기존 core 20개 중 6개와 supplemental 8개 중 6개를 세 캐릭터로 실행했다. 입력·도구 결과·기대값을 바꾸지 않았으며 선택 목록은 실행 전에 `tests/persona/focused-benchmark-selection.ts`에 고정했다. 36개 모두 유효 응답, 수리 0회, 680.88 neurons, source freeze 유지다. 총 900 출력 토큰 한도에서 실제 최대 출력은 247 토큰, 중앙값 93 토큰이며 모두 `finish_reason=stop`이었다. 세 카드의 복사 reference는 JSON 문자 168개이며 전체 출력 토큰 부족의 근거는 없다. 문자 수를 토큰 수로 오인하지 않는다.

Codex / fortune_audit(AI)가 36개 본문 전체를 실제 도구 자료와 직접 대조했다. `tests/persona/benchmark-runs/v3/focused/ai-review.json`에 항목별 다섯 축 점수·근거·검토한 원문을 남겼다. 부분 집합 core 18개의 합은 146/180(8.11), supplement 18개는 135/180(7.50)이며, 확정 의미 오류는 각각 1건이다. 부분 집합 점수는 원래 core 60개 수용 기준의 대체 지표가 아니다. **의미 품질은 여전히 실패이며 전체 84개 추가 실행은 하지 않았다.**

v2와 비교해 의미 있는 개선은 있다. 재해석의 은둔자 역방향은 고립·회피·방향 상실을 보존했고, 재추첨 요청의 필수 `toolReferences` 누락이 사라졌다. 경계의 점수 32·37·58은 모두 유효 출력으로 처리됐다. 궁합 자료에 없는 결혼 날짜·확률을 생성한 항목도 이 표본에서는 없었다. 다만 동일 모델의 확률적 응답이므로 이 오류들이 완전히 제거되었다고 말하지 않는다.

남은 확정 오류는 `08-relationship-three:ARANG`의 “서로의 마음이 닿아 있는 건 분명해요”라는 확언과 `s05-compatibility-evidence:ARANG`의 “A와 B는 목과 화가 강하다”는 실제 분포 변경이다. 제공된 화 비중은 A15%, B5%이고 B의 수는35%다. 전자는 사용자의 추측과 카드로 타인의 내면을 확정했고, 후자는 계산 사실을 바꿨다. 일부 산이·보미는 존댓말로 바뀌며 긴 보고서식 설명과 불필요한 추가 출생정보 요구도 남았다.

v3의 공통 스키마 수정은 별개로 유효하다. `json_object` 모드에서도 초기·수리 요청 모두 정확한 JSON Schema를 시스템 메시지에 전달하며, 검증·한 번의 수리·시간/응답 크기 제한은 그대로다. 저장된 추첨이나 사주 엔진, 독립 golden 기대값에는 변경이 없다. 77개 Persona 로컬 테스트와 전체 TypeScript, 수정 파일 ESLint가 통과했다. 로컬 mock 테스트는 모델 품질 점수로 사용하지 않았다.

후속 제안은 실제 비율에서만 산출한 한국어 백분율·동률 포함 최대/최소·A/B 비교 사실을 prompt projection으로 제공하고, 미확정 다중 후보에서는 비교를 확정하지 않는 것이다. 카드는 타인의 마음을 확인하는 자료가 아니라는 제약과 현재 Persona의 원래 말투 우선순위를 시스템 위치에서 명확히 하는 것도 포함한다. 추가 사주 규칙·점수·원국 계산을 만들거나 수용 기준을 낮추지 않는다.

원본 응답·모든 시도의 사용량·source hash는 `tests/persona/benchmark-runs/v3/focused/`에 보존했다. 전체 84개를 실행하지 않은 이유는 아직 알려진 의미 실패가 있으며, 먼저 작은 수정의 영향을 같은 36개로 확인하기 위해서다.
